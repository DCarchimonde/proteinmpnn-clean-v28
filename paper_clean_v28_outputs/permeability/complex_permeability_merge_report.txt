===== NOTES =====
Strict match is target + temperature + exact methylated design_seq.
Fallback match is target + exact methylated design_seq across temperatures. It is labeled as sequence_fallback_across_temperature.
Permeability is sequence-based; generation temperature is metadata, so exact-sequence fallback is acceptable if disclosed.
permeability_log10_positive_only is computed only for positive predictions; zero predictions remain NaN there.
permeability_log10_floor300 maps zeros to 1e-300 before log10 for plotting if a finite lower bound is needed.
This script does not calculate energy-based Success/Stability.
